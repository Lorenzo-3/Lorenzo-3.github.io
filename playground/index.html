Live experiments

Fourteen sketches, one shared graph

  • Graph Signal Diffusion

    Send a signal into one node and watch it travel through the local neighborhoods.

  • GNN Message Passing Toy

    Choose node features and add message-passing layers to see embeddings become smoother across edges.

  • Clustering Lab

    Place points in 2D, compare clustering algorithms, and adjust their grouping assumptions.

  • Gravity Assist Sandbox

    Send a probe through a miniature solar system and use flybys to reach the target planet.

  • Fourier Transform Playground

    Add sine waves one by one, listen to the mix, and watch the spectrum change.

  • Signal Filter Playground

    Apply classic filters to simple tones and compare the input, output, and frequency response.

  • MLP Decision Boundary Lab

    Build a tiny neural net, change its activations, and watch the learned boundary move as it trains.

  • Diffusion Model Denoising Toy

    Add noise to a generated image, then reverse a simplified denoising process step by step.

  • Convolution Kernel Playground

    Make your own 3x3 and 5x5 kernels and compare the convolved image with the original.

  • Image Color Editor

    Load or generate an image, adjust its colors, swap RGB channels, and save it as a PNG.

  • File Converter

    Convert images, audio, and video locally using native browser tools and FFmpeg.wasm.

  • Anomaly Node Game

    Watch the moving graph and pick out the node that reacts differently.

  • Computer Vision Mini Lab

    Small visual experiments to explore detection, saliency, reconstruction error, masks, and how to read images.

  • Circle of Fifths Network

    Explore a graph of keys, relative minors, and harmonic neighbors.
